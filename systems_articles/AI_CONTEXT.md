# Developer & AI Context Guide (general_articles - General Articles & Systems)
## Overview
This file serves as a system guide for any AI assistant or developer working inside the **general_articles** directory. This directory houses Tanvir Hussain's non-security technical articles, software architecture writeups, and sysadmin guides.

---

## 1. Build & Compile Process
To recompile general articles and update `index.html`, run the targeted monorepo build script from the repository root:

```bash
python3 build_all.py general_articles
```
