# CLEP Macroeconomics Graphs Lab

Live App: https://shadowpbx.github.io/CLEP_Macroeconomics_Graphs/

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
