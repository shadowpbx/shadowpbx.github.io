# Developer & AI Context Guide (general_tools - General Tools & Utilities)
## Overview
This file serves as a system guide for any AI assistant or developer working inside the **general_tools** directory. This directory houses Tanvir Hussain's non-security developer tools, automation scripts, and software utilities.

---

## 1. Build & Compile Process
To recompile general tools and update `index.html`, run the targeted monorepo build script from the repository root:

```bash
python3 build_all.py general_tools
```
