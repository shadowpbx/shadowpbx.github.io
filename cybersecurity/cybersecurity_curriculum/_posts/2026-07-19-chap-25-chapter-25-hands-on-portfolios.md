*   **Home Lab Architecture & Design:** Building a scalable virtualized enterprise sandbox environment using physical hypervisors (such as Proxmox VE, VMware ESXi, or local Type-2 solutions like Oracle VirtualBox) to safely test and audit security concepts.
*   **Active Directory Range Construction:** Scripting, deploying, and configuring realistic, intentionally vulnerable Active Directory laboratory networks from scratch to safely simulate and master modern domain exploit paths and defensive security operations.
*   **Capture the Flag (CTF) Documentation & Write-ups:** Structuring technical documentation and walk-throughs of target challenges solved on platforms like HackTheBox or TryHackMe, showing step-by-step methodology to demonstrate critical thinking to prospective employers.
*   **Open Source Security Contributions:** Creating, publishing, and documenting public code repositories on platforms like GitHub, showcasing a structured portfolio of custom automation utilities, detection rules, or parsing scripts.
